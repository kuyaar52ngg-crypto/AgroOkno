# Изменения контракта `app/src/data/contract.ts`

Только аддитивные изменения. Формат: дата · агент · что добавлено · зачем.

- 2026-10-23 · координатор · исходная версия контракта.
- 2026-10-23 · агент B · `AuthApi.requestRecovery` → в результат добавлено необязательное `demoCode?: string` (учебный код, UI подставляет его в ячейки A5 как на макете; на проде поле отсутствует).
- 2026-10-23 · агент B · `ReportPreview` → необязательные `respondent?: string`, `notes?: string[]`, `receipt?: Receipt | null`; в `sections[]` → `description?: string`. Нужны экранам C1–C5 (строка субъекта, пояснения, квитанция сданного отчёта).
- 2026-10-23 · агент B · уточнение (без изменения типов): для молока `quantity` в `ProductOutputEvent`/`ProductSaleEvent`/`NewEvent` — всегда килограммы; UI вводит литры и сам переводит (1 л = 1,03 кг, `litersToKg`/`kgToLiters` в `src/constants/format.ts`), мок хранит кг. Слой данных ничего дополнительно не пересчитывает.
- 2026-10-23 · агент B · `HouseholdMember.note?: string | null` — третья строка карточки члена ЛПХ (D1: «Участие в ведении хозяйства»).
- 2026-10-23 · агент B · новый хук `useUpdateProfile: () => Mutation<ProfileUpdate, Profile>` и тип `ProfileUpdate` (full_name/email/phone). Нужен экрану F2 «Данные хозяйства» (блок «Email · учебный контакт», «Телефон · необязательно»): контакты лежат в Profile, а `useUpdateFarm` их не покрывает. Агенту A: реализовать в реальном модуле и после этого `useAuth().profile` должен отражать изменения.
- 2026-10-23 · агент A · типы контракта не менялись. Реализован `useUpdateProfile` (добавлен агентом B). Договорённости реализации: `Profile`/`Farm` и все события читаются из локальной БД (expo-sqlite), `Query.fromCache = !online`, `Query.loading` — только первая загрузка без кеша; `demoCode` возвращается Edge Function `recovery` (демо-режим без отправки email/SMS); `HerdSummary.groups` — по одной строке на каждую группу (лошади — кобылы/молодняк/жеребцы отдельными строками); `getReportDownloadUrl`/`getReceiptUrl`/`HouseholdExtract.url` — ссылки на `/api/...` с `access_token` пользователя в query (для открытия в браузере).
- 2026-10-24 · координатор · v2: типы `SignUpInput`, `OnboardingStep`, `NewFarmInput`, `FarmLookup`, `JoinRequest`, `DeadlineReminder`, `ChatCard`, `ChatMessage`, `VoiceClip`, `AssistantChat`, `ReminderSettings`; члены `DataModule`: `signIn`, `signUp`, `verifySignUpCode`, `resendCode`, `useOnboardingStep`, `useCreateFarm`, `useFindFarm`, `useRequestAccess`, `useMyJoinRequest`, `useAssistantChat`, `useUpcomingDeadlines`, `useReminderSettings`, `useUpdateReminderSettings`, `registerPushToken`. Экраны R1–R8, J1–J8 (см. docs/TZ-v2.md).
- 2026-10-24 · агент C · типы контракта v2 не менялись (аддитивных правок нет). Договорённости реализации: `signIn` — RPC `resolve_login_email` (ИНН/email/телефон → технический email) + `signInWithPassword`; `signUp`/`verifySignUpCode`/`resendCode('signup')` — Edge Function `register` (демо-код в `demoCode`, как в `recovery`; `resendCode('recovery')` → `requestRecovery`); `useOnboardingStep`: `role` (нет роли) → `farm` (нет хозяйства) → `pending_access` (есть ожидающий запрос) → `null`; `useCreateFarm`/`useFindFarm`/`useRequestAccess` требуют сети (RPC `create_farm`/`find_farm`/`request_farm_access`), ошибки приходят как `Error` с русским текстом; `useAssistantChat.messages[0]` — всегда приветствие J1 с карточками ближайших сроков (id `greeting`, не хранится), дальше — история из `chat_messages` (90 дней) и неотправленные сообщения (`status: 'failed'`, только в памяти); `available` = есть сеть и сервер `EXPO_PUBLIC_API_URL` отвечает на `/health`; `sendVoice` при отключённом распознавании (503) ставит `error = «Распознавание речи не настроено — напишите текстом»` и не добавляет сообщений; `undoEvent` — мягкое удаление записи, карточка `saved_event` убирается, добавляется сообщение «Запись отменена. Надой удален из журнала.»; `useUpcomingDeadlines` считается локально (`app/src/reports/reminders.ts`, работает офлайн); `registerPushToken` — RPC `register_push_token` (ошибки не бросает). Хозяйство участника (одобренный запрос) для `useFarm`/`useAuth().farm` — то, чьим владельцем он не является; `Farm.owner_id` остаётся владельцем.
