- Маршрут, например `(tabs)/(home)/assistant` (кнопка «Моё хозяйство» сверху как в макете, иконка настроек → J8). Лента сообщений (пузыри пользователя и помощника, дата, «Вы · 09:42 · Отправлено»), карточки `ChatCard` (deadline / saved_event с кнопками «Изменить» и «Отменить запись» / how_to), подсказки-кнопки J1, поле «Напишите или скажите…» + кнопка микрофона ↔ «Отправить» (J2).
