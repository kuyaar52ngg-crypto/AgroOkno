# Моушн-графика трейлера АгроОкно

40 секунд, 1920×1080, 30 fps. Анимация написана кодом на [Remotion](https://www.remotion.dev/) (React → MP4). Используются цвета, шрифты (Unbounded, Onest) и логотип из макета Figma. Кредиты Flow не нужны.

| # | Время | Сцена | Файл |
|---|---|---|---|
| 1 | 0–6 с | Рассвет над аласом, снег, тайга | `scenes/Alas.tsx` |
| 2 | 6–11 с | Падают 5 бланков, штамп «ПРОСРОЧЕН»: «5 форм. 3 ведомства. Каждый месяц.» | `scenes/Paperwork.tsx` |
| 3 | 11–14 с | Появление логотипа и слогана | `scenes/LogoReveal.tsx` |
| 4 | 14–18 с | Телефон с главным экраном: отчётность, быстрые действия, счётчики | `scenes/Home.tsx` |
| 5 | 18–22 с | Голосовой ввод: волна, распознанная фраза, «Надой сохранён» | `scenes/Voice.tsx` |
| 6 | 22–26 с | Журнал учёта → линии → Росстат / Минсельхоз / Сахастат «Сдан» | `scenes/Fanout.tsx` |
| 7 | 26–33 с | «Меркурий» и похозяйственная книга, push-напоминание о сроке | `scenes/Farmer.tsx` |
| 8 | 33–40 с | Финальная карточка | `scenes/EndCard.tsx` |

Длительности сцен и переходов заданы в `src/theme.ts`.

## Запуск

```bash
cd tools/trailer
npm install
npm run studio    # редактор в браузере: таймлайн, перемотка, правки на лету
npm run render    # → media/trailer/agrookno-motion.mp4
npm run still     # один кадр → media/trailer/frames/motion-still.png
```

`npm run prepare-assets` (вызывается автоматически) копирует в `public/` шрифты из `app/node_modules` и логотип из `docs/figma`. Поэтому перед первым запуском нужно выполнить `npm install` в `app/`.

## Ролики Google Flow (необязательно)

Сцены 1, 2 и 7 — места для видео из Flow. Если в `media/trailer/clips/` лежат файлы
`01-alas-dawn.mp4`, `02-paperwork.mp4` или `07-happy-farmer.mp4` (их скачивает MCP `agro-flow`, промпты — в `docs/trailer/storyboard.md`), сцена берёт ролик: медленный наезд и подпись поверх. Если файла нет, показывается графика.

Музыка: положите `media/trailer/music.mp3`. Она подхватится с плавным появлением и затуханием, а звук роликов отключится.

## Лицензия Remotion

Remotion бесплатен для физических лиц и компаний до 3 сотрудников (команда хакатона подходит). Для компании побольше нужна [лицензия](https://www.remotion.dev/license).
