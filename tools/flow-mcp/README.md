# agro-flow MCP

MCP-сервер АгроОкно для демо-трейлера: генерирует ролики в **Google Flow** (Veo) через отдельный профиль Chrome и собирает трейлер через ffmpeg.

> Flow не имеет публичного API — сервер управляет веб-интерфейсом Flow в вашем аккаунте. Это может сломаться при изменении интерфейса и может противоречить условиям Google. Используйте на свой риск, только свой аккаунт.

Написан с нуля по мотивам подхода [GTAI-1/flow-mcp](https://github.com/GTAI-1/flow-mcp) (у того репозитория нет лицензии, код не заимствован).

## Установка

```bash
cd tools/flow-mcp
npm install
npm run build
npm test          # проверка сборки трейлера (ffmpeg из ffmpeg-static)
```

Сервер подключён к Claude Code через `.mcp.json` в корне репозитория (`agro-flow`). После сборки перезапустите Claude Code и одобрите сервер.

## Вход во Flow

`npm run open` (или инструмент `flow_open`) открывает **отдельный** Chrome-профиль `~/.agro-flow-mcp/chrome-profile` с flow.google.com. Войдите в Google сами, откройте или создайте проект. Пароли MCP не вводит и не хранит.

## Инструменты

| Инструмент | Что делает | Кредиты |
|---|---|---|
| `flow_status` | вход, проект, настройки, очередь, правила планирования | — |
| `flow_open` | открыть окно Flow | — |
| `flow_generate` | поставить сцены в очередь (по одной, пауза 20–45 с) | видео — да, только с `confirm_spend: true`, лимит `max_credits` на сцену |
| `flow_wait` | дождаться прогресса (≤ 40 с), вернуть статусы | — |
| `flow_cancel` | отменить ещё не начатые сцены | — |
| `flow_assets` / `flow_download` | список и повторное скачивание готовых плиток | — |
| `trailer_assemble` | сборка: ролики, титры, экраны приложения, наезд камеры, переходы, логотип, музыка | — |
| `trailer_frame` | кадр для предпросмотра | — |

Файлы по умолчанию — `media/trailer/` (в git не попадают). Раскадровка демо-трейлера — `docs/trailer/storyboard.md`.

## Переменные окружения
`AGRO_FLOW_OUTPUT`, `AGRO_FLOW_HOME`, `AGRO_FLOW_CHROME`, `AGRO_FLOW_CDP_PORT` (9334), `AGRO_FLOW_PAUSE_MIN_S` / `AGRO_FLOW_PAUSE_MAX_S`, `AGRO_FFMPEG`, `AGRO_FONT_TITLE`, `AGRO_FONT_BODY`.

## Безопасность
- Порт отладки Chrome слушает только `127.0.0.1`; пока окно Flow открыто, любой локальный процесс может им управлять — закрывайте окно после работы.
- Режим Flow «Agent» (генерация без подтверждения) MCP выключает.
- В панели аккаунта Flow MCP ничего не нажимает.
