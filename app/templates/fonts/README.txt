Onest (Regular, SemiBold) - шрифт под лицензией SIL Open Font License 1.1 (OFL).
Файлы взяты из пакета @expo-google-fonts/onest (Google Fonts); пакет распространяется под MIT (см. LICENSE-expo-google-fonts.txt).
Используются в серверных функциях для PDF с кириллицей (квитанции, выписка из похозяйственной книги).
